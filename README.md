# Yankho & Friends — Operation Apex

A clean, responsive multi-page static website designed for GitHub Pages.

## Pages

- `index.html` — Home
- `about.html` — Our story and values
- `team.html` — Friends/team page with the supplied photo
- `apex.html` — Operation Apex
- `contact.html` — Contact page
- `style.css` — All styling
- `script.js` — Mobile navigation and contact interaction
- `assets/friends.jpg` — Supplied background/team image

## GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and the `assets` folder, keeping the same structure.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Easy customization

- Change names and descriptions in `team.html`.
- Replace `your-email@example.com` in `contact.html` and `script.js`.
- Change the website title/branding in the `<title>` tags and header.
- Add more project cards to `apex.html`.

No PHP, database or server is required, so it works well with GitHub Pages.
